Математический мод для Mindustry. Добавляет единицы как ресурсы. Первый шаг к математике.

- 0.02-0.99: нет планеты
- 1.00-1.99: есть планета
- 2.00-2.99: и ещё планета
- и так далее, пока идеи не закончатся 

## Важно

Мод в активной разработке. Контента пока немного, но он будет расширяться с каждой версией.

## Установка

1. Скачай `Alef-Null.zip` из [раздела Releases](https://github.com/oscillatorium/Alef-Null/releases) на GitHub
2. В игре: Моды -> Импорт мода -> Локально
3. Выбери скачанный ZIP-архив (не распаковывай)

Или поищи в браузере модификаций Alef-Null, так как мод есть в браузере модификаций.

# Alef-Null (en)

A mathematical mod for Mindustry. Adds numbers as resources. The first step into mathematics.

## Version number syndrome

- 0.02–0.99: no planet
- 1.00–1.99: planet included
- 2.00-2.99: and one more
- and so on until I run out of ideas

## Important

This mod is under active development. There isn't much content yet, but it will expand with every version.

## Installation

1. Download `Alef-Null.zip` from the [Releases section](https://github.com/oscillatorium/Alef-Null/releases) on GitHub
2. In the game: Mods → Import Mod → Local
3. Select the downloaded ZIP archive (do not unpack)

Or just search for Alef-Null in the in-game Mod Browser — the mod is already there.
