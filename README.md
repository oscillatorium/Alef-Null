# Alef-Null

Математический мод для Mindustry. Добавляет единицы как ресурсы. Первый шаг к математике.

## Что добавляет сейчас

- Ресурс: Единица (1) - зелёная монетка (вообще ничего не делает)
- ядро: аксиома - должна производить энергию, но не работает
- бур, который послужил источником бесконечных дебагов
- конвейер, который атакует моральным уроном

## Синдром обозначения версий

- 0.02-0.99: нет планеты
- 1.00-1.99: есть планета

## Важно

Мод в активной разработке. Контента пока немного, но он будет расширяться с каждой версией.(сейчас в медленной разработке, так как я немного пофигист)

## Установка

1. Скачай `Alef-Null.zip` из [раздела Releases](https://github.com/oscillatorium/Alef-Null/releases) на GitHub
2. В игре: Моды -> Импорт мода -> Локально
3. Выбери скачанный ZIP-архив (не распаковывай)

Или поищи в браузере модификаций Alef-Null, так как мод есть в браузере модификаций.
